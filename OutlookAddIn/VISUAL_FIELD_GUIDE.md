## Column Descriptions

### Field Name
- **What**: User-friendly display name
- **Example**: "Activity"
- **Use**: For understanding what the field is

### Reference Name
- **What**: System identifier for the field
- **Example**: "Microsoft.VSTS.Common.Activity"
- **Use**: Official field identifier, copy for configuration

### Type
- **What**: Data type of the field
- **Values**: String, Integer, TreePath, Identity, DateTime, Double
- **Use**: Understanding what kind of values to use

### Usage
- **What**: Where the field is used
- **Values**: System, Custom, Internal, Computed
- **Use**: Determining if you can modify the field

### Description
- **What**: Information about the field
- **Example**: "Describes the type of activity for the work item"
- **Use**: Understanding the field's purpose

## Common Tasks

### Task 1: Find a Custom Field
```
1. Click "View Fields"
2. Look for Reference Names starting with "Custom."
3. Copy the Reference Name
4. Use short name in configuration
Example: Custom.MyTeam ? Use "MyTeam" as key
```

### Task 2: Find Valid Values
```
1. Click "View Fields"
2. Check Description column
3. Or create a test bug
4. Check Debug Output for actual values set
```

### Task 3: Understand Field Requirements
```
1. Click "View Fields"
2. Check "Usage" column:
   - System = standard Azure DevOps field
   - Custom = added by your organization
   - Internal = system-only, can't modify
3. Look at "Type" for value format
```

### Task 4: Debug Field Issues
```
1. Create a bug with your configuration
2. Open Visual Studio Debug Output
3. Find "========== WORK ITEM FIELDS =========="
4. Look for your field and its actual value
5. Verify it matches your configuration
```

## Troubleshooting Visual Guide

### Problem: Fields Won't Load
```
? Possible causes:
   1. Organization URL incorrect
   2. Project Name incorrect
   3. PAT invalid or expired
   4. Network error

? Solution:
   1. Verify Organization URL starts with https://
   2. Check Project Name matches exactly
   3. Regenerate PAT token
   4. Check internet connection
```

### Problem: Field Not Found Error
```
? You tried to set: Custom.FoundInEnvironment
? Error: Cannot find field

? Solution:
   1. Click "View Fields"
   2. Search for similar field names
   3. Check if field exists in your project
   4. Copy the exact Reference Name
   5. Use short name in configuration
```

### Problem: Value Not Accepted
```
? You set: Activity = "InvalidValue"
? Error: Value not accepted

? Solution:
   1. Click "View Fields"
   2. Find the Activity field
   3. Check Type (should be String)
   4. Use valid values: Development, Testing, Deployment
   5. Try again
```
